## Not stated, so assumed

- Score formula (weights are free): non-decisive family 12 + up to 6 for hit count; decisive 22 + up to 9; rhythm kinds 8; capped at 100, then the PRD's caps and floors applied. Interval: 30 bootstrap resamples of sentences (6 when window > 20k chars), fixed seed.
- Lexical lists "implementer's choice" (4, 69, label wording, slugs) are my own lists. Inflections are generated by simple suffix rules.
- Character-layer counts (62, 66, 67, 68) use the raw window; lexical and structural rules use the window with code/blockquote/table/badge/front-matter masked. `homoglyphs` counts mixed-script runs, not characters.
- Size caps use `statSync` size. Unsupported extensions in `check` answer "no readable text". A NotebookEdit payload with only `file_path` is scored; an apply_patch line without a colon names no path. Tool names outside the five are ignored.
- Ledger file: `.prosecheck-ledger-<session id, sanitised>` (`.prosecheck-ledger` with no id). Ledger records for repeated `id` in transcripts are de-duplicated by message id (max usage kept).
- Caps for labels: guard 5, check 8, show 5.
- If the shipped Cursor rule is missing under the plugin root, `init` reports "cannot write" for the rule instead of using a built-in copy.
- Cleanup of a document whose cleaned text is empty prints nothing and exits 0 (input was non-empty).
- Hook/ledger records the guard adds for files not on disk use the reason "file could not be read".
