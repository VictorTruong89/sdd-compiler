# Changelog

Changes to the lending rules, newest first. Each entry is the board's decision on that date.

## 2026-05-10
- The borrowing limit is lowered to **3** tools at once per member, after the spring shortage. The
  loan specification still shows the old number in one place; this entry is the current rule.
- The overdue report now lists equally overdue loans by item id (it used to be by member id).

## 2026-03-02
- Power tools are lent for 7 days (see the counter notes).
- Members must give an email address when they register.

## 2026-01-15
- First version of the Lend specifications, replacing the spreadsheet.
